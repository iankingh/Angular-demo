## Getting Started / 快速開始

### Prerequisites / 環境需求

- Node.js >= 12
- Angular CLI: `npm install -g @angular/cli`

### Run a project / 執行專案

```bash
# Navigate to any project, e.g.
cd forms/angular-hero-form

# Install dependencies
npm install

# Start dev server (default: http://localhost:4200)
ng serve
```
